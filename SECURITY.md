# Security policy

Please don't report security vulnerabilities in public issues. Report them
privately through GitHub's [private vulnerability reporting](https://github.com/AlaaSarhan/cookiejar/security/advisories/new)
instead. You'll get an answer within a week.

Security fixes are made for the latest release of each component.

The receiver stores evidence of consent and the banner runs on every page of a
site, so issues in either are of particular interest, e.g. ways to inject
records, to read records without the admin token, or to inject script through
banner options or a report.
